# Simple sample API
## Configuration
Rename/copy the `.env.dist` file to `.env` and set the missing variables:

```dotenv
API_KEY=
LITACKA_API_URL=http://private-264465-litackaapi.apiary-mock.com
LITACKA_API_KEY=
```

## Running
In your console run these commands:

```bash
$ npm install
$ npm start
```

## API
API itself runs at `https://localhost:3000/`

OpenAPI specs are available at `http://localhost:3000/docs`
